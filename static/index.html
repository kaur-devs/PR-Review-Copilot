How it works

The cheap half

A curated set of linter rules chosen by what they cost, not by how many they catch. Deterministic, instant, and free — so the model's budget is spent only on the judgements a model is needed for.

The expensive half

Agents that pull in the definitions and callers around a change before deciding anything. Each candidate is then re-checked by a separate judge with no memory of the agent that proposed it.

webhook → snapshot → diff → context ─┬─ lint ───┐ │ ├─→ judge → gate → post └─ agents ─┘

A finding is dropped if the judge cannot confirm it, if the severity is too low to be worth a comment, or if this repository has shown it does not act on that kind of finding.

What it does not do

  • Python, JavaScript and TypeScript only. Other files in a pull request are skipped, not guessed at.
  • One instance, free tier. Reviews run one at a time, and a webhook arriving during a restart is lost rather than queued.
  • It does not resume mid-review. An interrupted review restarts from the beginning on the next boot.
  • It is not a merge gate. It comments; it never approves, blocks or pushes code.

Install it

Pick the repositories it can see. Open a pull request. It comments within about half a minute.
